## Trabalho SGI - Computação Gráfica UFSC

Implementação do sistema gráfico interativo desenvolvido ao longo do semestre.

- Transformações de viewport
- Transformações em 3D e 2D
- BSPlines e Curvas de Bezier genéricas
- Clipping
- Projeção em perspectiva e paralela

### Execução

Para versões mais atuais do python é necessário criar um ambiente virtual

```
python3 -m venv env
```

Instalar as dependências

```
pip install -r requirements
```

Executar script main.py

```
python3 main.py
```
